# Sarah Khan’s portfolio

A static portfolio with a typed introduction, experience and project highlights, and Orbit, a custom F1/space word game.

Open `index.html` directly, or run `python3 -m http.server 8000` and visit http://localhost:8000. No build is required.

Personal photos can replace the two illustrated snapshots in `index.html`. The résumé is in `assets/sarah-khan-resume.pdf`.

Orbit supports physical and on-screen keyboards, six guesses, duplicate-letter scoring, and new rounds. Its word list comes from [tabatkins/wordle-list](https://github.com/tabatkins/wordle-list).
